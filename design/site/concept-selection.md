# Concept selection (Fable 5.2, creative call 2 of 5, 13 Nov 2026)

**Ranking: 1 The Line, 3 One Object, 2 Two Seconds, 5 Everything It Says, 4 In Place.** Only The Line can reach Site-of-the-Year level, and not yet: as built it's a tidy dev-tool page. One Object is the new fallback, replacing Two Seconds.

**Truth bugs found:**
- "never 0%" is false: the panel prints `0% left` with an `as of` stamp on stale evidence (`glance-model.js` `limitLines`).
- Quoted times disagreed with the live panel beside them.
- Half of concept 5's "Never" column was invented.

## Pushed into The Line
1. **First screen gets One Object's discipline:** a one-line lede, each question with one line of answer, then the command and GitHub, then empty space.
2. **Show the command that actually gets copied:** the full clone line, wrapped.
3. **First branch is In Place's tray legend,** "Closed, it's a number". Its rows are generated by the panel's `trayLabel` from the same fixture, so the counts always agree.
4. **Honesty section, three real contrasts:**
   - `couldn't check · tried HH:mm`, not a 0;
   - a reset date, not a countdown;
   - `Can't reach T3 Code`, not `0 running`.

   Every string is read from the live fixture, followed by Two Seconds' offline line: "When it can't see, it says so."
5. **Sources fit in one sentence:** "Works with T3 Code today. Next: …".
6. **The phone signature is the trunk:** it starts from the panel's own rail at its last node, and both questions sit above the panel.
7. **The line travels twice:** when the story reopens, the page line sweeps again with the panel.
8. **The trunk uses the panel's stroke, nodes, radius and 260 ms draw.**

## Avoid
- Invented strings.
- A second panel, a sticky panel, scroll-scrubbing.
- Cards or tiles.
- Patching the panel's wrapped dates in site CSS.
- Claiming "two seconds" as a headline.
