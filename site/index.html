The count in your menu bar or tray is how many agents are running. A mark after it says why you might look.

And one notification when a limit runs low: once for each window, when what's left drops to 10% or the level you set, until that window resets.

It stays on your computer.

No cloud, no account, no telemetry. Nagi only reads, so it can't stop, send or approve anything.

Its reader listens only on 127.0.0.1 and answers only you. To watch another computer, it connects over your own Tailscale.

To check your limits, it uses your own sign-in and sends it only to that provider.

It only says what it knows.

Install Nagi

Linux or macOS, with Python 3.11 or newer. The installer keeps the data, owner key and connections you already have, and asks before it uses sudo.

git clone https://github.com/yeqiuqiu123/nagi.git && cd nagi && ./install.sh

Then Nagi opens and walks you through connecting your agent apps, read-only.

On Linux it needs GTK 3, WebKitGTK 4.1 and an AppIndicator tray, and the installer tells you if one is missing. On a Mac it builds the menu-bar app with Swift from Xcode or the Command Line Tools.
